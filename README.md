## 프로젝트 소개
* React 입문 개인과제
* 2024 파리 올림픽을 모티브로, 각 국가별 메달을 집계할 수 있는 사이트 
* 작업기간 : 2025.01.21 ~ 2025.01.24
* 작업자 : 이기리

<br>

## 주요기능
* 사용자 입력을 통해 메달 집계 리스트가 화면에 출력 (Create / Read)
* 삭제 버튼을 통해 리스트 개별 삭제 가능 (Delete)
* 업데이트 버튼을 통해 메달 집계 리스트의 데이터를 수정 (Update)
